# Mussas

Sitio web para un salón de belleza. El proyecto permitirá mostrar los trabajos realizados, informar la ubicación del salón y agendar horas.

## Estado

Base mínima de React con Vite, sin diseño ni funcionalidades implementadas todavía.

## Desarrollo

Requiere Node.js 20.19+ o 22.12+ y pnpm.

```sh
pnpm install
pnpm dev
```

## Compilación

```sh
pnpm build
pnpm preview
```

## Funcionalidades previstas

- Galería de trabajos y servicios del salón.
- Ubicación e información de contacto.
- Agenda para reservar una hora.
